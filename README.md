# Air Radar

3D-трекер самолётов: Three.js, OSM/Overpass и серверный FR24 web feed.

## Запуск

```sh
npm ci
npm run build
npm start
```

Открыть http://localhost:8787. Для разработки: `npm run server` и `npm run dev` в отдельных терминалах; Vite проксирует `/api` на порт 8787.

## Хранение

- Настройки области, фильтров и отображения — в localStorage.
- Активные и завершённые треки — в IndexedDB этого браузера.
- OSM — в IndexedDB: срок актуальности 7 дней, лимит 100 МБ, вытеснение давно использованных областей.
- При недоступности Overpass показывается сохранённая карта, включая устаревшую, с предупреждением.
- Сервер проксирует запросы FR24/Overpass и не записывает настройки, карты или треки на диск.
- Старые локальные файлы `data/` не загружаются, не импортируются и не публикуются.

Данные изолированы по браузеру и адресу сайта. Очистка данных сайта удаляет историю и карты; браузер также может освобождать своё хранилище при нехватке места. Ошибка сохранения показывается отдельно, текущий сеанс продолжает работать в памяти. Открытые вкладки одного сайта используют общую IndexedDB; последняя запись истории побеждает.

## Управление

- **APPLY** применяет настройки; для новой области сначала проверяется браузерный кэш.
- **REFRESH MAP** принудительно запрашивает свежий OSM, обходя кэш. Использует уже применённую область.
- Нажатие на маркер самолёта открывает рейс, тип, регистрацию, маршрут, высоту, скорость и возраст данных.
- Фильтр ищет по рейсу, позывному, типу, регистрации и аэропортам текущих самолётов; для истории доступны сохранённые рейс и тип.
- **PAUSE** останавливает запросы самолётов и их анимацию; **RESUME** возобновляет наблюдение.
- Переключатели управляют картой, активными треками и историей. Высотный масштаб подписан в легенде.
- На карте показаны основные дороги и здания от 5 этажей. Сложные building relations пока не отрисовываются.

Треки прореживаются по расстоянию/высоте/времени и ограничены 600 точками каждый с сохранением начала и конца. Сохраняются до 500 завершённых проходов (по настройке), до 256 активных. Отсутствие новых данных более минуты завершает проход. Смена области завершает активные проходы. Отображение движения прогнозируется приблизительно; источник не предназначен для навигации.

## API и источник

- `GET /api/health`
- `GET /api/aircraft?lat=55.6&lon=37.4&radiusM=5000`
- `GET /api/osm?lat=55.6&lon=37.4&radiusM=5000`

Поддерживаются широты −85…85°, долготы −180…180°, радиус 250…30000 м. Каждый запрос задаёт собственную область; общих настроек пользователей на сервере нет.

FR24 legacy web feed — неофициальный нестабильный источник; формат или доступность могут измениться. Адаптер находится в `server/providers/fr24Web.js`. Вертикальная скорость в этом формате не подтверждена и отображается как недоступная. При ошибках интервалы запросов увеличиваются до минуты.

OSM запрашивается последовательно у доступных публичных Overpass-инстансов, до 28 секунд на каждый. При ошибках диагностика выводит хост и сетевую причину. Публичные серверы могут быть перегружены. Атрибуция: © OpenStreetMap contributors.

Переменные окружения: `PORT`, `FR24_LIVEFEED_URL`, опционально `OVERPASS_URL` для приоритетного сервера. Node автоматически не читает `.env`.

## Публикация и тесты

Render Web Service: Build Command `npm ci && npm run build`, Start Command `npm start`, health check `/api/health`. Постоянный диск не требуется. `render.yaml` предназначен для создания нового сервиса; существующий сервис обновляется из подключённой ветки main.

```sh
npm test
npm run build
npm run test:browser
```

Браузерные тесты используют установленный Google Chrome в headless-режиме и локальные ответы-фикстуры, без нагрузки на FR24/Overpass.
